## 交付边界

管理 API 和管理台可按 README.md 本地启动。原生客户端的强制校验代码已经接入，但**不能将源码与语法检查视为已经发布或完成真实远控验证**。

正式使用前仍须完成：

1. 在具有 Rust、Flutter、MSVC／平台编译工具和 vcpkg 依赖的环境构建 Flutter 原生客户端，并运行已有客户端测试与新增测试。
2. 用至少两台机器验证公司账号登录、按组目录、合法远控、越权 ID 输入、旧客户端拒绝、错误密码重试、人工确认、文件传输／终端／隧道／摄像头权限隔离，以及管理服务断线时拒绝连接。
3. 在目标 Linux 服务器构建并启动 Docker Compose，验证 HTTPS、服务账号读取的被控端配置路径、备份恢复和管理员账号发放。

已经建立的远控会话不会因撤权立即断开；Web 远控引擎尚未接入；`view` 只允许目录查看，不代表屏幕只读。这些限制在 README.md 中有完整说明。
