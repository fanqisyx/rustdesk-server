# Windows 公司管理服务 v1.1.17-company.1（预发布）

为已运行 hbbs.exe／hbbr.exe 的 Windows 10 x64 服务器增加公司账号、资产分组、权限、设备分享和审计。API 与客户端 v1.5.1-company.1 兼容，schema v2。现有中继、ID 服务及密钥无需替换。

附件 `rustdesk-server-company-windows-x86_64-v1.1.17-company.1.zip` 包含独立 `rustdesk-management.exe`、Caddy、WinSW、两个服务配置和安装脚本；使用者不必另装 Python 或 Docker。此为现有服务器的管理扩展包，不包含 hbbs/hbbr；完整源代码在本仓库，管理扩展源码另有 ZIP 附件。

解压到独立目录后，在目标服务器的管理员 PowerShell 中执行：

```powershell
.\windows\Install-Management.ps1 -PublicIp '替换为自己的固定公网IPv4'
```

脚本交互创建管理员，不提供默认密码；检查端口及服务冲突，以 LocalService 安装管理 API 和 HTTPS，启用自动启动及失败重启，只增加本管理服务的防火墙规则。不会停止、替换或重配已有 hbbs/hbbr。可先加 `-WhatIf` 查看计划。

要求公网 TCP 80/443 可达，以申请并自动续期 Let's Encrypt IP 证书。脚本成功及 Windows 服务运行中不代表证书已经签发：必须用外网访问 `https://公网IP/healthz`，确认有效证书后再迁移客户端。证书有效期短，续期需要服务器持续运行并保留 data/caddy。

新账号默认无设备权限，设备需管理员登记和授权。被控端需要公司版客户端及逐台独立凭据，原版客户端／仅替换 hbbs/hbbr 无法执行集中授权；新被控端会拒绝无票据的旧控制端。先使用两台电脑试点，再分批迁移。

已建立的远控会话不会被撤权立即断开；Web 远控和 Sciter 账号界面暂不支持。客户端安装包位于 fanqisyx/rustdesk 的 v1.5.1-company.1 Release。本版安装与验证步骤见压缩包 README 及 management/windows/README.md。

管理 API 业务沿用已验证的客户端首版服务，增加 Windows 打包和部署，不改变 hbbs/hbbr 网络行为。验证结果见 management/VALIDATION.md；目标公司公网证书签发、路由器映射及双机远控仍须现场验收。
