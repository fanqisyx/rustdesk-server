# Windows 图形安装包与中文说明书 v1.1.17-company.2

在公司管理服务首版基础上增加可双击的 Setup.exe，安装时填写公网 IPv4 与管理员密码。无需另装 Python 或 Docker，原有 hbbs/hbbr 继续运行；配套客户端仍为 v1.5.1-company.1，管理 API 0.1.0、schema v2 保持兼容。

## 下载文件

- rustdesk-server-company-v1.1.17-company.2-Setup.exe：推荐的 Windows x64 图形安装包。
- RustDesk-Windows-Server-Manual-zh-CN.pdf：六页中文说明书，涵盖安装、首次登录、纳管、权限、分享、备份、卸载与排错；也内置在安装包中。
- Windows 管理扩展 ZIP：供需要手动部署的人使用。
- 管理扩展源码 ZIP、release-manifest.json、SHA256SUMS：来源与校验信息。

安装向导需要管理员权限，默认目录为 C:\Program Files\RustDesk Company Server，要求使用空目录。自动检查端口、目录及服务冲突，不停止未知服务；创建开机自启的 API 与 HTTPS 服务。密码通过临时进程环境传递，不写入命令行、注册表或配置文件。

Windows 应用列表及开始菜单提供卸载入口。卸载核对服务所属目录，只删除本扩展服务和发布文件，保留 data 中的数据库及证书，不递归删除未知文件，也不卸载 hbbs/hbbr。当前安装包未做代码签名，请核对来源及 SHA256 后按公司策略使用。

公网 TCP 80/443 必须能到达服务器，HTTPS 使用 Let's Encrypt 的短期 IP 证书并由 Caddy 自动续期。服务显示 Running 不代表证书已经签发，须从外网确认有效 HTTPS，再用两台电脑完成纳管与远控验收。

管理 API 业务规则未改变。管理员初始化参数校验失败时改为通用错误，避免把无效密码写进安装日志，并增加对应回归测试。
