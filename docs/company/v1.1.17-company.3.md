# 可选明文 HTTP 管理服务 v1.1.17-company.3

增加无需域名、无需证书、不使用 80/443 的独立 HTTP 安装包。适用于已有 hbbs.exe/hbbr.exe、固定公网 IP、需要独立管理端口的 Windows x64 服务器。

- 下载 `rustdesk-server-company-v1.1.17-company.3-HTTP-Setup.exe`，填写实际公网 IPv4、HTTP 端口（默认 21114，可改为其他 1024 至 65535 端口）及管理员密码。
- 仅安装 `RustDeskCompanyAPI` 服务，监听 `0.0.0.0:所选端口`，仅为该 EXE 放行所选 TCP 端口。不安装或启动 HTTPS 服务，不申请证书，不检查或占用 80/443。
- 原 `Setup.exe` 保留原 HTTPS 部署路径，需要 80/443。两个模式不能同时安装，也不能直接覆盖现有管理扩展。已有管理扩展先停止、备份整个 data、卸载，在空目录新装并恢复 data；旧 hbbs/hbbr 不变。
- HTTP 客户端必须升级到 [v1.5.1-company.2](https://github.com/fanqisyx/rustdesk/releases/tag/v1.5.1-company.2)。控制端填写 `http://自己的公网IP:21114` 并勾选允许明文 HTTP；被控端额外设置同值 `enterprise-http-origin`，完整配置见更新的中文 PDF 和 Windows README。

HTTP 会明文传输账号密码、登录令牌、设备凭据和连接票据，链路窃听或篡改可能使账号和设备权限被冒用。需要链路保密时使用原 HTTPS 模式或在受保护的 VPN 网络中使用。HTTP 包和客户端均明确显示明文提示，未改变现有 HTTPS 证书校验，也没有自动降级。

账号、设备分组、权限、分享及 API/schema 不变。卸载核对服务和防火墙规则所属路径，仅删除本应用的程序文件，保留数据库及其他 data。当前安装包未做代码签名。

回归表面：原 `Uninstall-Management.ps1` 增加仅针对本程序的 HTTP 防火墙规则清理；`build_windows_setup.py` 增加可选 HTTP 编译入口，默认编译路径不变；打包 manifest、README、PDF 和 CI 增加 HTTP 信息。安装器、预检查和服务部署逻辑均放在新增的 HTTP 专用文件。现有 HTTPS 安装脚本、Caddy 配置、Rust hbbs/hbbr 及子模块未改变。

本地 API 19 项测试、Dart 六项请求测试、原生授权模块四项测试通过。新增 CI 验证 HTTP 安装器拒绝所选端口冲突、实际安装为 LocalService、HTTP 注册登录及卸载保留数据库，具体结果以本标签工作流为准。真实公网映射和公司双机远控仍须试点验收。
